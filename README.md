# Crabionics Site

Public website for Crabionics Aquaculture Private Limited.

## 2026 website narrative

Crabionics is building **production infrastructure + an operating system for precision mud crab aquaculture**.

The public technology spine is:

**Habitat → CrabSense → CrabPod → AquaOS**

The website follows an evidence-first rule: architecture and implementation are separated from field validation and commercial claims.

## Main routes

- `/validation` — validation architecture and current programme
- `/aquaos` — AquaOS operating layer
- `/capital` — capital/evidence thesis

- `/about` — company hypothesis and programme
